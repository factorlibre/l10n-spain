This module prints the AEAT VERI*FACTU QR code on Point of Sale tickets.

The QR code is placed at the top of the ticket, before any other content,
with a size of 35 mm, error correction level M and the "VERI*FACTU" legend.
It is enabled per Point of Sale.

The QR code only contains the issuer VAT, the simplified invoice number, the
date and the total amount (negative for refunds), so it is generated in the
browser and works offline. The QR code URL is stored on the order.
